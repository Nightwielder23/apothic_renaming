# Apothic Renaming

NeoForge 1.21.1 mod that lets you rename Apotheosis affixed items in a vanilla anvil. The custom name replaces Apotheosis's prefix/suffix decoration without needing the Sigil of Unnaming. Affixes, sockets, and rarity color stay intact.

Server-side, soft dependency on Apotheosis, always on when Apotheosis is loaded.
